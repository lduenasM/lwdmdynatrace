# Ejercicios Junior

Hazlos en **no-prod**. Anota URLs.

**J1.** Encuentra tu MZ y un servicio de tu equipo. Captura (sin PII) el nombre exacto en Dynatrace.

**J2.** En los últimos 60 min: throughput, failure rate, p95 (o equivalente en tu UI).

**J3.** Abre un PurePath lento. Escribe: entry, span que se lleva el tiempo, status.

**J4.** Mismo intervalo: un log ERROR del mismo servicio (o indica “no hay correlación”).

**J5.** Host o workload del servicio: CPU y memoria. ¿Saturación sí/no y por qué?

**J6.** Redacta un mensaje de escalamiento de 6 líneas (plantilla del doc 05).

**J7 (opcional).** Lista 3 tags de la entidad. Si no hay tags, eso es un hallazgo para el buddy.

No uses LLM con datos de estos ejercicios.
