# Glosario

| Término | Significado corto |
| --- | --- |
| **ActiveGate** | Puente/proxy: red, cloud, sintéticos privados, ingest |
| **Alerting profile** | Filtro de quién se entera de un Problem |
| **APM** | Monitoreo de rendimiento de aplicación (servicios, trazas) |
| **Baseline** | Comportamiento “normal” aprendido |
| **Bucket (Grail)** | Contenedor de datos con retención/permisos |
| **Burn rate** | Velocidad a la que se come el error budget |
| **Cardinalidad** | Número de series únicas métrica×dimensiones |
| **Copilot (Davis CoPilot)** | IA generativa en el tenant (NL, DQL) |
| **Davis AI** | Correlación causal; Problems y RCA |
| **Deep monitoring** | Instrumentación rica del proceso (no solo infra) |
| **DQL** | Lenguaje de consulta de Grail |
| **Entity** | Objeto monitorizado (host, servicio, pod…) |
| **Error budget** | Margen de fallo que permite el SLO |
| **Grail** | Lakehouse de Dynatrace |
| **Management Zone (MZ)** | Recorte de visibilidad |
| **Master** | En este kit: **sinónimo de Senior** |
| **Metric event** | Regla de evento/umbral definida por el equipo |
| **Monaco** | Monitoring as Code |
| **OneAgent** | Agente de instrumentación en el host/workload |
| **OpenTelemetry (OTel)** | Estándar de trazas/métricas/logs |
| **Problem** | Incidente correlacionado por Davis |
| **PurePath** | Traza de punta a punta en Dynatrace |
| **RCA** | Causa raíz (candidata) |
| **RED** | Rate, Errors, Duration |
| **RUM** | Real User Monitoring |
| **Sampling** | Guardar un subconjunto de trazas |
| **Senior** | Nivel 4 = Master: plataforma y gobierno |
| **SLI / SLO** | Indicador / objetivo de nivel de servicio |
| **Smartscape** | Mapa de dependencias observado |
| **Sintético** | Monitor robot (HTTP o browser) |
| **Tenant / environment** | Instancia de Dynatrace de la empresa |
| **USE** | Utilization, Saturation, Errors |
