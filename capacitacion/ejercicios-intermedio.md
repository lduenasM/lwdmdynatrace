**I4.** Una sesión RUM o un user action (si política lo permite) → API → servicio.

**I5.** Un sintético: última falla. ¿Script, dependencia o outage?

**I6.** Workload K8s: restarts vs impacto RED. No uses un nombre de pod viejo como ID.

**I7.** DQL: 20 líneas de log de error de *un* servicio, `limit 20`, ventana 15 min.

**I8.** Redacta qué **no** pegarías en Jira de un PurePath que muestra un documento.
